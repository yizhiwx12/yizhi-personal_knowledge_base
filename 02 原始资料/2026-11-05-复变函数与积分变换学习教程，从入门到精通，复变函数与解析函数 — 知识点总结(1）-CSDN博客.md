**验证 C-R 条件：**

```matlab
syms x y real
u = x^2 - y^2;           % 给定 u
v = 2*x*y;               % 给定 v

% 验证 C-R 方程
du_dx = diff(u, x);
dv_dy = diff(v, y);
du_dy = diff(u, y);
dv_dx = diff(v, x);

CR1 = simplify(du_dx - dv_dy)    % 应为 0
CR2 = simplify(du_dy + dv_dx)    % 应为 0
matlab运行123456789101112
```
